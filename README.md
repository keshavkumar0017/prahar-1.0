# 🏏 Prahar Model of Scouting (Version 1.0) | Next-Gen T20 Predictive Roster Engineering

**Prahar 1.0** is an independent, algorithmic sports analytics framework engineered to mathematically evaluate, scout, and optimize T20 cricket rosters. By shifting the paradigm away from traditional career aggregates and surface-level volume metrics, the Prahar engine maps a player's performance dynamic across core situational match-day pressure constraints.

---

## 🚀 The Vision: An Independent Roster Intelligence System
The ultimate goal of the Prahar project is to build an autonomous, highly accurate scouting engine capable of simulating live draft scenarios, predictive chemistry matching, and real-time phase re-balancing. 

Rather than viewing player metrics in a vacuum, Prahar models a cricket team as a fluid, interconnected software architecture where weakness in one phase requires automated tactical padding in another. This release (v1.0) sets the baseline calculation layers for full-scale situational analysis.

---

## 🧠 Core Engineering: The Macro-Phase Exposure Model
Prahar 1.0 breaks down a standard T20 match data registry into three distinct, non-linear macro-phases: the Powerplay, the Middle-Overs Engine Room, and the Finishing Phase. 

The software isolates and solves two critical dynamic vulnerabilities that routinely crash team efficiency baselines:
1. **Middle-Phase Scoring Stagnation:** Deploys a specialized Spin-Choke Resolution Index (SCRI) to neutralize high-dot-ball choking strategies (e.g., handling severe 36.2% dot-ball squeezes against spin) and sustain scoring velocity.
2. **Late-Innings Run Equity Drag:** Implements a customized Death-Overs Blockhole Engine (DOBE) to calculate pace acceleration capacity, boundary mitigation factors under scoreboard velocity, and lower-order collapse protection.

---

## 🛠️ The 25-Tier Capability Matrix & Weight Allocations
The engine passes dataset variables through twenty-five discrete situational and matchup criteria layers (`C01` to `C25`). Instead of a rigid, uniform baseline, weights dynamically adapt to the asset's primary strategic placement:

* **Top-Order Accelerators:** pointed heavily on Pace Strike Rate (50%) and Target Setting capability (30%) to guarantee aggressive initial phase capitalization.
* **Middle-Overs Choke Breakers:** Evaluated on Spin Strike Rate (55%) to efficiently break defensive bowling traps.
* **Lower-Order Finishers:** Concentrated on Pace Strike Rate (60%) and second-innings Chasing indices (30%) under high target deficits.
* **Multi-Utility Flex Modifiers:** Compounded multipliers applied dynamically for roster padding, incorporating dual-skill versatility (Wicketkeeping option +8% score value / Bowling flexibility +5% score value).
* **Demographic Trajectory Layers:** Integrated point-triggers for regional talent optimization and long-term youth growth models to identify high-integrity assets before peak market value realization.
